Welcome to the Restaurant Menu API

Search restaurant menus: given a dish, find the restaurants that serve it.

Methods

Get all restaurants

Endpoint: http://localhost:5000/get-all-restaurants

Request type: GET

Request body: none

Response: JSON array of restaurants, ordered by name, e.g. 

  [
  {
    "address": "292 Massachusetts Ave, Cambridge, MA 02139",
    "name": "Roxy's Grilled Cheese",
    "website": "https://roxysgrilledcheese.com"
  }
]

Find restaurants by dish

Endpoint: http://localhost:5000/find-restaurants-by-dish/<dish_name>

Request type: GET

Request parameters: "dish_name", the name of a desired dish

Response: JSON array of the restaurants that serve a matching dish, e.g. 

[
  {
    "address": "292 Massachusetts Ave, Cambridge, MA 02139",
    "name": "Roxy's Grilled Cheese",
    "website": "https://roxysgrilledcheese.com"
  }
]
